# RadioMate 후원 순간 실제 화면 캡처

PC Chrome·Edge에서 선택한 **스푼 방송 탭의 현재 보이는 영역**을 후원 이벤트 수신 후 즉시·1·2·3·4초에 최대 5장 연속 PNG로 저장하는 Manifest V3 확장 기능입니다. 방송 화면을 재구성하거나 후원 인증 이미지를 생성하지 않습니다. 모바일 스푼 앱의 화면 캡처는 지원하지 않습니다.

## 설치와 연결

1. 라디오메이트 DJ 관리 화면의 **기록 · 보상 관리 → 후원 순간 실제 방송 화면 캡처**에서 ZIP을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 `manifest.json`이 있는 폴더를 선택합니다.
3. DJ 관리 화면에서 **캡처 연결 정보 발급 → 연결 정보 복사**를 누릅니다. 실제 DJ 계정으로 로그인한 사용자만 발급할 수 있습니다.
4. PC 스푼 웹에서 **같은 DJ의 실제 방송 탭**을 엽니다. 확장 아이콘을 눌러 연결 정보를 붙여넣고 대상 DJ 확인란을 체크한 뒤 **현재 방송 탭 연결**을 누릅니다. URL과 대상 DJ를 반드시 확인하세요.
5. **5장 연속 테스트**로 실제 화면이 저장되는지 확인합니다. 테스트 파일 이름에는 `TEST`가 포함됩니다. 이후부터 수신하는 새 후원을 감지합니다.

파일은 브라우저 기본 다운로드 폴더의 `RadioMate-Captures/날짜/시간_DJ_청취자_수량spoon_이벤트_frame01.png`에 저장합니다. 다운로드가 차단되면 확장 팝업의 상태를 확인하세요. 저장 위치 정책은 브라우저 설정을 따릅니다.

이미 설치한 경우 새 ZIP의 파일로 기존 확장 폴더를 교체한 뒤 확장 관리 화면에서 새로고침하고 방송 탭을 새로고침·재연결하세요. 버전은 `1.1.2`입니다.

연결 전에도 실제 스푼 방송 탭에서 확장을 열어 **5장 연속 테스트**를 누르면 수동 PNG 저장을 확인할 수 있습니다. 이 테스트는 DJ 로그인·연결 정보·서버 호출 없이 해당 탭만 촬영하며, 자동 후원 감지 연결을 만들지 않습니다.

## 동작 범위

- `events.donation` 권한으로 서버가 받은 실제 후원 이벤트가 트리거입니다. 청취자의 충전·결제 화면, 결제 금액, 카드·계좌 정보는 수집하지 않습니다. 충전만 하고 DJ에게 후원하지 않은 경우에는 캡처하지 않습니다.
- 방송 탭이 활성 상태이고 창이 최소화되지 않아야 합니다. 다른 탭·다른 방송으로 이동했거나 후원 시각에서 10초가 지났으면 건너뜁니다. 후원이 없을 때 임의로 화면을 저장하지 않습니다(사용자가 누른 테스트 캡처 제외).
- 감지에는 네트워크·약 1초 폴링 지연이 있습니다. 후원 감지 직후부터 약 4초 동안 1초 간격으로 실제 화면 5장을 저장해 모션 전후를 담습니다. 동영상·GIF 녹화나 모션 요소 인식이 아니므로 모션이 늦게 나타나거나 표시 설정이 꺼져 있으면 포함되지 않을 수 있습니다. 같은 조회에서 수신한 여러 후원은 화면 5장을 공유하며 파일명에는 마지막 후원의 DJ·청취자·수량이 표시됩니다. 스티커 애니메이션의 특정 프레임이나 후원 팝업이 반드시 보이는 것을 보장하지 않습니다. 서버·브라우저가 꺼진 동안의 과거 순간을 복원하지 않습니다.
- 페이지 새로고침·브라우저 재시작 후 확장 팝업에서 다시 연결하세요. 신규 연결은 그 시점 이후 이벤트부터 감지합니다. 후속 후원은 앞선 연속 캡처가 끝난 뒤 감지하며 브라우저 제한에 맞춰 간격을 두고 처리합니다. 탭 변경·연결 중지 시 남은 프레임을 중단하며 늦어진 이벤트는 건너뜁니다.
- 연결 정보는 해당 DJ의 후원 트리거 조회만 허용하고 DJ 로그인이나 설정 변경 권한을 주지 않습니다. 12시간 후 만료되며 재발급·서버 연결 해제·스푼 연결 해제 시 이전 연결이 무효화됩니다.
- 확장은 서버에서 트리거만 받아오며 **PNG를 서버 또는 다른 서비스로 업로드하지 않습니다**. 연결 정보는 이 확장의 로컬 저장소에만 보관합니다. 로컬 중지는 팝업의 중지, 서버 발급 해제는 DJ 화면의 서버 연결 해제를 사용하세요.
- PNG에는 보이는 채팅·닉네임·방송 이미지가 포함될 수 있습니다. 저장 파일은 PC에서 직접 보관·삭제합니다. 서버의 청취자 삭제는 PC에 이미 내려받은 PNG를 삭제하지 않습니다. 서버의 트리거 대기열은 최근 2분·최대 100건입니다(정리는 최대 1분 지연).

## 검증 범위

자동 테스트는 후원 SSE 감지·중복 제거·DJ별 권한·만료·탭 변경·최소화·지연·5장 촬영 시각·동시 후원·촬영 중지·PNG 전달 경로를 검증합니다. 확장 설치 후 실제 후원 순간의 PNG 저장은 실제 Chrome·Edge와 방송에서 별도로 확인해야 합니다.

2026-11-22 실제 Windows Edge에 1.1.2를 설치하고 스푼 방송 URL에서 수동 5장 연속 테스트를 실행했습니다. 다운로드 완료 표시, PNG 5개 파일의 서명·921×920 크기·파일 저장 간격(861/1010/1000/1000ms), 마지막 파일의 화면을 확인했습니다. [검증 수치](../../test/evidence/donation-capture-edge.json)는 이미지·계정 정보 없이 기록합니다. 당시 스푼은 비로그인 상태여서 저장 화면에 로그인 안내가 포함됐습니다. **실제 후원 이벤트가 발생한 순간의 모션 포함 여부는 미검증**이며, 로그인한 방송과 연결된 DJ의 새 후원 이벤트로 추가 확인해야 합니다. 테스트 PNG 원본은 PC에만 보관합니다.

청취자 음성 입력
설치와 사용

무엇을 할 수 있나요?

PC 스푼 웹에서 듣고 있는 방송의 채팅 입력창에, 한국어로 말한 문장을 자동 입력합니다. 내 청취자 계정의 입력창을 돕는 기능입니다.

전송은 스푼 화면에서 직접 누릅니다. 봇 이름으로 전송하거나 DJ 방송을 제어하지 않습니다. 스푼 모바일 앱에는 연결하지 않습니다.

1. PC 브라우저에 설치

  1. 제공된 RadioMate-청취자음성입력.zip을 압축 해제합니다.
  2. Chrome의 확장 프로그램 관리 화면을 엽니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  4. manifest.json이 있는 폴더를 선택합니다.
  5. 브라우저의 확장 메뉴에서 Radio Mate를 고정하면 편합니다.

스토어 등록 전 개발용 확장입니다. 설치는 사용자가 직접 진행합니다. 음성 인식 서비스 지원은 브라우저·기기·네트워크에 따라 달라질 수 있습니다.

2. 내 청취자 계정으로 사용

  1. 스푼 웹에 로그인하고 듣고 싶은 방송에 들어갑니다.
  2. 그 방송 탭에서 Radio Mate 확장 버튼을 누릅니다.
  3. 현재 스푼 채팅 입력창이 자동으로 연결됩니다. 연결되지 않으면 방송의 채팅 입력창 선택을 누르고 해당 입력창을 클릭합니다.
  4. 말하기를 누른 뒤 마이크 사용을 허용합니다.
  5. 한 문장을 말하고 잠시 멈추면 인식 결과가 채팅 입력창에 붙습니다.
  6. 내용을 확인하고 스푼에서 전송합니다.

자동 입력 체크를 끄면 인식 문장을 수정한 뒤 채팅 입력창에 넣기를 누를 수 있습니다. 인식 한 번마다 말하기를 다시 누릅니다.

기존 글과 오류 처리

기존 채팅 초안 뒤에 덧붙이며, 한 번 인식한 문장이 중복 입력되지 않도록 요청 ID를 확인합니다. 도우미는 초안 포함 최대 200자로 제한합니다. 스푼 입력창 자체의 더 짧은 제한이 있으면 그 제한을 따릅니다.

방송 주소 변경·입력창 교체·입력 비활성화·마이크 거절·네트워크 실패 시 자동 입력을 중지하고 이유를 표시합니다. 방송을 바꾸거나 새로고침했다면 해당 방송에서 확장 버튼을 다시 누르세요.

스푼 화면 구조가 변경되면 수동 선택이 필요할 수 있습니다. 텍스트 자동 입력으로 채팅 제한이나 계정 권한을 우회하지 않습니다.

음성과 개인정보

말하기 버튼을 누른 동안만 한 문장을 인식합니다. 마이크가 열린 채로 계속 대기하지 않으며, 취소·창 닫기에서 인식을 중지합니다.

브라우저 제공자의 서버에서 음성을 인식할 수 있습니다. 민감한 말은 인식하지 마세요. Radio Mate 서버에 녹음·채팅 이력을 업로드하지 않으며, 브라우저 종료 후 복구할 음성 기록을 저장하지 않습니다.

확장은 activeTab·scripting만 요청합니다. 방송 탭에서 사용자가 확장 버튼을 눌렀을 때 해당 탭의 입력창만 돕습니다. 계정 비밀번호·쿠키·API 키를 읽지 않습니다.

검증 범위

2026.11.17 스푼 비로그인 방송 페이지에서 실제 입력 요소가 textarea이며 placeholder가 ‘대화를 입력하세요.’인 것을 관찰했습니다. 구조 확인만 했고 실제 방송에 테스트 글을 넣거나 전송하지 않았습니다.

입력 연결·중복·기존 초안 보존·길이·음성 이벤트는 로컬 테스트로 확인합니다. 실제 확장 설치 상태의 마이크 인식·로그인·방송 전송은 사용자 실환경 확인이 필요합니다. 스푼 공식 제공 또는 승인 확장으로 표시하지 않습니다.

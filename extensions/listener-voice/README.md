# Radio Mate · 청취자 음성 입력

PC 스푼 웹의 청취자 채팅 입력 도우미입니다. DJ 관리 기능이나 봇 전송 기능이 아닙니다.

## 사용

1. 이 폴더를 Chrome 확장 프로그램 관리 화면의 **압축해제된 확장 프로그램 로드**로 설치합니다. 개발자 모드가 필요합니다.
2. 본인의 스푼 계정으로 로그인하고 청취할 방송에 들어갑니다.
3. 해당 방송 탭에서 확장 버튼을 누릅니다.
4. 입력창 자동 연결을 확인합니다. 안 되면 입력창 선택 버튼을 누르고 방송의 채팅 입력창을 직접 클릭합니다.
5. 말하기를 누르고 마이크 사용을 허용한 뒤 한 문장을 말합니다.
6. 인식이 끝나면 기존 채팅 초안 뒤에 문장을 붙입니다. 자동 입력을 끄면 수정 후 입력할 수 있습니다.
7. 실제 전송은 스푼 화면에서 직접 누릅니다.

Chrome에서의 실제 음성 인식 가능 여부는 장치·브라우저·네트워크와 음성 인식 서비스 상태에 따라 다릅니다. 스푼 모바일 앱에는 연결하지 않습니다.

## 개인정보와 권한

- manifest 권한은 activeTab·scripting입니다. 사용자가 확장을 누른 현재 방송 탭에만 연결합니다.
- 스푼 비밀번호·쿠키·토큰을 조회하지 않습니다. 서버·DB·OAuth 앱 없이 입력을 보조합니다.
- 마이크는 버튼을 눌렀을 때만 한 문장을 인식합니다. 취소하거나 창을 닫으면 중지합니다.
- 브라우저의 음성 인식 서비스로 음성이 전송될 수 있습니다. Radio Mate 서버에는 녹음이나 채팅 이력을 보내지 않습니다.
- 입력 요청 ID로 중복을 막고 기존 초안을 지우지 않습니다. 도우미의 초안 한도는 200자입니다.

## 구현·검증

- background.mjs: 사용자가 고른 방송 확인과 입력 연결 코드 주입, 전용 창 열기
- bridge.js: 현재 스푼 textarea 탐색 또는 수동 선택, 기존 글 뒤에 입력, 주소·입력 상태·길이·중복 확인
- speech.mjs: 한국어 단일 발화, 확정 결과만 전달, 취소·늦은 이벤트 차단
- panel.mjs: 인식·수정·자동 입력·복사와 상태 안내
- test/listener-voice.test.mjs: 주소 제한·인식 취소·중복·기존 초안·길이·비활성 입력 테스트

2026-11-17 스푼 방송 페이지의 실제 textarea 구조를 읽기 확인했습니다. 실제 방송에는 글을 넣거나 전송하지 않았습니다. 자동 테스트는 서비스의 음성 인식·로그인된 스푼 계정의 입력 반영을 보장하지 않습니다. 설치 뒤 실제 환경 확인이 필요합니다.

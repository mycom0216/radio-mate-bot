• 21개 지역 격자(nx,ny)가 RSS 헤더와 전부 일치
• API와 RSS를 17곳×4일(68건) 비교: 차이 25건
• 차이는 오늘(RSS는 남은 시간 기준 부분값)과 11-22 강수확률(10%p)뿐
• 내일·모레 값은 17개 지역 모두 동일
• 초단기실황·미세먼지(대표 측정소 원본값)·특보(전남 강풍주의보) 응답 확인
• 네이버 화면 수치와의 대조는 사용자 수치 필요(미수행)
상시 운영 자동 복구
• 문제: 봇이 두 번 한꺼번에 종료(코드 0xC000013A, 콘솔 종료)
• 원인(추정): 숨은 콘솔 창이 닫히며 관리자·서버·터널이 함께 종료
• 해결: conhost --headless 실행기 → 콘솔 없는 --daemon 관리자 → 서버·터널 분리 실행
• 15초 헬스체크, pid 이어받기, 고정 공용 주소 갱신
자동 복구 · 검증
• 관리자 강제 종료 후에도 서버·터널·공용 주소 200 유지
• 다음 감시 틱(≤5분)에 새 관리자가 같은 PID를 이어받음
• 낡은 pid가 다른 프로그램을 가리켜도 건드리지 않고 31초 만에 새 서버로 복구
• 서버 교체 중 중단은 몇 초~40초
• 한계: 재부팅·장기 운영은 지표로 측정하지 않음

## 검증 범위와 사용

PDF는 갱신한 Word 내용에서 별도로 구성한 열람본으로 전 페이지를 렌더링 점검했습니다. Word와 PDF의 페이지 나눔은 같다고 보장하지 않습니다. 번들 LibreOffice가 없어 `render_docx.py`의 네이티브 Word 배치 검증은 완료하지 못했습니다. Word 원본은 편집용이며 제출 PC에서 열어 표·그림 배치를 확인하세요.

PPTX는 28장을 렌더링하고 패키지·배치·재가져오기 검사를 통과했습니다. Microsoft PowerPoint 앱에서 슬라이드 쇼를 직접 확인한 결과는 아닙니다. Excel은 실적과 일정 미정의 후속 작업을 구분합니다.

기존 전체 화면·ERD·날씨·Android 그림은 11월 19일 판 자료입니다. `dining-desktop.jpg`와 `dining-results.jpg`는 11월 20일 새 기능 화면입니다. Android 새 빌드나 실방송 장기 인수를 이번에 완료했다고 주장하지 않습니다.

실제 계정·토큰·API 키·운영 DB·원본 음성은 포함하지 않습니다. 전체 문서 압축본에는 작성용 `_build`와 임시 미리보기를 제외합니다. 앞선 11월 18일·19일 판은 그대로 보존합니다.

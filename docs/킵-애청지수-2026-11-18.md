# 청취자 킵과 애청지수 안내 개선

## 킵

- 프로필이 없는 청취자도 `!킵`으로 자동 등록·조회한다. 본인의 보유 내역만 보여준다.
- `!킵 사용 1` / `!킵 사용 보상명`: 묶음 목록에서 보상 한 개를 빼고 `kind: used` 이력을 저장한다. 번호는 현재 목록 기준이다.
- `!킵 완료`: 사용 내역을 최신순으로 표시한다.
- `!킵 취소`: 최근 본인 사용을 복원한다. `!킵 취소 1` / `!킵 취소 보상명`으로 지정할 수 있다. 원래 이력은 `cancelled`로 남고, 같은 건은 다시 복원하지 않는다. 청취자는 DJ가 처리한 사용을 되돌릴 수 없다.
- 기존 한국 시간 월간 초기화를 유지하고 유효기간을 채팅·관리 화면에 표시했다. 매월 말일 23:59:59까지 보유하고 다음 달 00:00부터 비운다. 서버 중단 중 경계를 넘으면 다음 실행·조회에서 반영한다. 지난달 사용 취소를 통한 만료 보상 복원을 차단한다. 기록은 보관한다.
- 게임 개인 대기시간과 킵 조작을 분리했다. 방송 전체 응답 간격과 킵의 1초 개인 제한은 유지한다. 관리 화면의 보유·이력은 입력 중이 아닐 때 다음 조회 주기에 갱신한다.

## 애청지수

- 기존 청취·채팅 점수를 변경하지 않고 1점=1°로 표시하는 상승 안내를 추가했다. 스푼 공식 애청온도와 별개임을 메시지에 포함한다.
- 5분 간격으로 최근 집계 이후 증가분·누적을 알린다. 최초 확인을 기준으로 시작하며 증가가 없으면 보내지 않는다. 사용자가 채팅한 시간의 기여도 포함한다.
- 복권 하루 지급 한도 이후에도 안내한다. 여러 사람의 안내를 200 UTF-16 코드 단위 이내로 묶어 outbox에 넣고 기존 송신 간격을 지킨다. 메시지 수에 따라 실제 수신 시각은 늦어질 수 있다. 조용 모드·OFF 설정에서는 안내를 만들지 않는다.
- `!애청지수`는 현재 지수·최근 집계 상승분·청취 시간·채팅 기여를 표시한다. 게임 설정에서 자동 안내를 끌 수 있다.

## 검증

- 청취자 권한으로 최초 조회 → 사용 → 완료 이력 → 취소 → 보유 복원의 실제 HTTP 경로를 테스트했다.
- 번호·이름 지정, 타인 보상 보호, 이벤트 중복 처리, 여러 장 중 한 장 사용·복원, 게임 대기시간 분리와 중복 복원 방지를 검증했다.
- 한국 시간 월말 자정, 윤년 2월, 12월→1월, 지난달 사용 취소 거부를 시간을 제어해 검증했다. 실제 월말까지 기다린 검증은 아니다.
- 애청지수 5분 집계, 청취·채팅 합산, 중복 스냅샷, 복권 한도 이후 안내, 한글·이모지 긴 닉네임의 묶음 길이와 공식 지수 구분을 검증했다.
- 실방송 채팅의 실제 수신과 휴대폰 표시 확인은 모의 송신·HTTP 테스트와 구분한다.

## 상점 구매 개선

- 기존 구매 동작에 `!구매` 단축 명령과 정확한 아이템 이름 검색을 추가했다. `!구매 rare`, `!아이템 구매 1`, `!구매 희귀 물고기 확률 UP`을 지원한다.
- 상점은 번호·한글 이름·ID·PT 가격·구매 및 사용 방법을 보여준다. 긴 상점은 명시적 페이지 조회로 나눈다.
- PT를 차감해 가방에 하나 추가하고 차감액·잔액·보유 개수·사용 명령을 응답한다. 자동 사용하지 않는다. 품절·판매 중지·잔액 부족·모호한 이름·잘못된 추가 인자는 차감하지 않는다.
- 같은 이벤트 재전송 시 이중 결제하지 않으며 한정 재고를 두 청취자가 초과 구매하지 않는 것을 확인했다. 긴 게임 대기시간은 구매·가방·사용에 적용하지 않되 방송 전체 응답 간격과 아이템 요청 1초 제한은 유지한다.
- 실제 HTTP에서도 DJ가 테스트 PT를 지급한 뒤 청취자 권한의 `!구매 exp`로 PT 차감·가방 저장을 확인했다.

최종 전체 자동 테스트: 174개 통과(node --test). 로그: deploy/keep-affinity-shop-tests.log(로컬 전용). 중간 병렬 실행에서 HTTP 연결 초기화가 한 번 발생했으나, HTTP 단독 재실행과 최종 전체 실행에서는 재현되지 않았다.

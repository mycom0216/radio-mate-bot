# 설치형 웹앱 · 재생 복원 · 자동 퀴즈 검증

2026-11-18, `radio-mate-bot` 체크아웃 기준.

## 구현

- manifest, 기존 라디오 그림을 재사용한 아이콘, iOS/Android 설치 안내, 설치 가능한 브라우저의 설치 버튼, 연결 끊김 안내를 추가했다.
- 서비스 워커는 공용 오프라인 HTML/CSS/아이콘 세 개만 보관한다. DJ HTML·API·OAuth·음성 접수 링크·음성 데이터는 캐시하지 않는다. 오프라인에서 변경 요청을 저장하거나 재전송하지 않는다.
- 재생 위치는 5초마다, 일시정지·앱 전환·페이지 이탈 시 저장한다. 동일 방송·곡 ID·영상 ID일 때만 복원한다. 다른 영상으로 교체·삭제된 곡에 적용하지 않으며, 완료·로그아웃 시 지운다. 유효기간은 12시간이며 만료 후 조회 시 삭제한다. 강제 종료 시 마지막 수 초는 저장되지 않을 수 있다. 새 설치 웹앱의 저장소 공유 여부에 따라 기존 브라우저 위치가 전달되지 않을 수 있다.
- YouTube 배경 재생을 만들지 않았다. 화면을 떠나면 멈추고, 돌아와 사용자 재생 버튼으로 재개한다. 웹앱을 설치해도 브라우저 완전 종료 후 오디오가 남는 구조는 아니다. 스푼 방송에 오디오를 자동 주입하는 기능도 아니다.
- 자동 퀴즈는 기본 10분 간격의 선택 설정이다. 기존 방송에는 사용자 요청에 따라 켜며 신규 방송은 기본 OFF다. 첫 정답자 한 명, 정답·시간 종료 후 다음 출제, 개인 문제 중 대기, 조용 모드·방송 종료 시 중지, 한 순환 내 문제 중복 방지를 지원한다.
- Spoon이 전송 성공을 확인한 뒤 공용 문제를 활성화한다. 전송 재시도 시에는 활성화하지 않고, 결과가 불명확하면 같은 문제를 무한 재송신하지 않는다. 실패가 계속되면 관리 화면 기록을 확인해야 한다.

## 확인한 범위

- 전체 Node 테스트 **158개 통과**: `node --test`, 로그 `deploy/pwa-auto-quiz-tests.log`(로컬 전용).
- 실제 HTTP에서 manifest·SVG 아이콘·SW 경로와 MIME, 캐시 지시문을 확인했다.
- 저장소 재생성 후 위치 복원, 다른 방송/곡/영상 차단, 만료·손상된 저장값·저장소 차단 처리, 완료 후 위치 삭제를 검증했다.
- 숨긴 페이지의 새 재생 시작 차단, 서비스 워커의 비공개 경로 우회, 기존 신청곡·방송 기능 회귀 테스트가 통과했다.
- 자동 퀴즈 간격·초성/분류·선착순 보상·시간 초과/뜻 공개·개인 문제 대기·DJ 권한·설정 검증·전송 실패·Spoon 스케줄러 호출을 제어된 시간과 모의 송신으로 검증했다.
- 브라우저 390×844 화면에서 모바일 설치 안내와 자동 출제 설정 저장을 확인했다.

## 남은 실기기 확인

실제 iPhone/Android에서 홈 화면 추가, 설치된 웹앱의 DJ 로그인, YouTube 외부 재생 허용 영상의 소리 출력과 위치 복원, 실제 방송 채팅에서 자동 문제 송신/정답 보상을 확인해야 한다. 자동 테스트와 화면 점검이 이 검증을 대신하지 않는다.

공식 제한: [YouTube API Developer Policies, III.I.9](https://developers.google.com/youtube/terms/developer-policies#i.-additional-prohibitions).

공용 HTTPS에서 manifest의 200 응답, application/manifest+json MIME, standalone 모드를 확인했다. [모바일 웹앱 화면](assets/pwa-mobile-20261118.jpg)

운영 배포: 연결된 전체 방송에 켜 달라는 사용자 확인 후, 현재 연결된 1개 방송에 퀴즈 사용·자동 출제·10분 간격을 적용했다. 적용 전 SQLite 백업, 사용자 데이터 동일성, quick_check=ok, 공용 서버 health=ok를 확인했다. 신규 방송의 기본값은 OFF이며 DJ가 켤 수 있다.

추가 신청곡 개선: 접수 즉시 자동재생 시도 스위치를 기본 ON으로 추가했다. 열린 화면의 대기열에 새 곡이 있고 현재곡·선택곡·정지 상태가 없으면 약 4초 내 재생을 시도한다. 명시적 정지와 숨긴 페이지를 우회하지 않는다. 로컬 실제 브라우저에서 !신청곡 YouTube 링크만 입력하고 재생 명령·재생 버튼 없이 플레이어가 재생 중으로 바뀐 것을 확인했다. 기기 오디오 출력이나 닫힌 모바일 브라우저의 재생을 검증한 것은 아니다. [접수 자동재생 화면](assets/request-autoplay-20261118.jpg)

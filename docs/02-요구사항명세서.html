요구사항 명세서

사용자 행동, 예외 처리, 인수 기준을
실제 구현 근거와 함께 연결합니다.

상태 표기

FR-02의 외부 실방송 인수를 제외한 기능은 현재 소스에 구현되어 있습니다. 자동 테스트의 통과가 실환경 연동 성공을 뜻하지는 않습니다. Must는 이번 프로젝트의 핵심, Should는 운영 보조 기능입니다.

목차와 추적 체계

용어

용어정의
DJ로그인된 방송 운영자. API에서 세션의 room으로 권한 범위를 제한한다.
청취자방송 채팅에서 명령을 보내는 참여자. 공개 음성 접수 닉네임은 계정 인증이 아니다.
EXP / PT팬랭킹용 누적 경험치 / 게임·상점용 포인트. 현금 또는 결제 잔액이 아니다.
킵룰렛 보상 보관 목록. DJ가 사용 처리한다.
설정 revision오래된 화면이 다른 변경을 덮어쓰지 못하도록 비교하는 버전 값.

FR-01 · 로그인 / 모드 Must

주체 DJ / 방문자
정상 동작 로컬 환경에서 연습 화면을 열고 실제 미연결 상태를 표시한다. 운영 환경에서는 연습 로그인을 허용하지 않는다.
인수 기준 / 예외 로컬 POST /api/demo 성공, 운영 조건에서는 제공 안 됨. 화면에 연습 배너 표시.

구현·검증 근거: server.mjs · test/server.test.mjs

FR-02 · 스푼 연결 Must

주체 DJ
정상 동작 설정된 OAuth 앱으로 동의한 DJ의 방송을 연결하고 SSE 이벤트를 처리한다.
인수 기준 / 예외 미설정이면 연결 버튼 비활성화. 승인 앱·실계정의 연결·갱신·송신은 별도 수동 인수.

구현·검증 근거: spoon.mjs · server.mjs

FR-03 · 대시보드 Should

주체 DJ
정상 동작 청취자·EXP·대기곡·보상 대기를 표시하고 해당 관리 메뉴로 이동한다.
인수 기준 / 예외 데이터와 카드 값 일치, 네 카드와 빠른 이동 버튼이 해당 메뉴로 전환.

구현·검증 근거: public/app.js · public/studio-icons.mjs

FR-04 · 설정 저장 Must

주체 DJ
정상 동작 입력 변경을 표시하고 명시적 저장 후 적용한다. 기존 설정을 백업한다.
인수 기준 / 예외 미저장 바 표시. 동일 revision 저장 성공, 이전 revision은 409로 거절.

구현·검증 근거: server.mjs · test/server.test.mjs

비기능 요구사항

ID / 분류요구사항과 확인 기준
NFR-01 보안인증 세션·CSRF·출처 검사 적용. API는 세션 방송에 한정하고 토큰은 AES-256-GCM 암호화 저장. 권한·암호화 테스트 통과.
NFR-02 일관성보상·잔액·도감·감사 기록을 트랜잭션으로 묶고 실패 시 롤백. 이벤트 ID 및 복권 잔액 버전으로 중복/경합 방지.
NFR-03 사용성로컬 연습 배너, 명시적 저장, 미저장 이동 확인, 실패 원인 안내. 주요 동작은 한국어로 표시.
NFR-04 반응형390px / 1440px 전체 메뉴에서 페이지 가로 넘침 없음. 긴 표는 컨테이너 안에서 스크롤. 실제 기기는 추가 검증.
NFR-05 접근성의미 있는 이미지 설명, 장식 aria-hidden, 명령 입력 label, 포커스 표시와 동작 줄이기 지원. WCAG 인증·전체 대비 검수는 미수행.
NFR-06 운영상시 Node 프로세스·영구 SQLite/음성 볼륨 필요. 동일 DB 다중 인스턴스 금지. 서버 재시작 시 웹 세션 종료.
NFR-07 성능대량 복권 집계는 이벤트 루프에 양보하고 매우 큰 수량은 범주 표본화. 동시 사용자 수·SLA·처리량 목표는 부하측정 후 확정.
NFR-08 개인정보공개 링크는 업로드만 가능, 파일 조회는 해당 DJ 인증. 보관기간은 DJ 삭제 전까지인 현재 동작이며 공개 전 정책 확정 필요.

NFR은 현재 방어 로직과 인수 목표를 기술합니다. 성능 수치, 보안 인증, 사용자 만족도 같은 미측정 지표를 달성했다고 표시하지 않습니다.

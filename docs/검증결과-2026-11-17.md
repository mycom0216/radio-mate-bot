## 수정 사항

- DJ 프로필 생성 거부와 후속 명령의 생성 요구가 충돌하던 흐름을 수정했다. `!내정보`는 자동 생성 후 조회하고, DJ의 첫 개인 명령에서도 프로필을 준비한다. 재생성으로 잔액이나 출석을 초기화하지 않는다.
- 같은 신청곡의 영상 링크 변경 시 새 영상을 불러온다. 현재곡 삭제 후 이전 음성이 계속 재생되지 않도록 정지한다.
- 신청곡과 음성 수신함을 주기적으로 갱신하며 편집 중인 입력과 청취 중인 음성을 보존한다.
- 음성 파일의 HTTP Range 요청을 지원한다. 활성 음성 링크는 서버 시작 시 현재 공용 주소로 갱신한다.
- 로컬·공용 서버의 중복 방송 연결을 해소하고 기존 DJ 데이터를 공용 서버에서 사용한다. localhost 관리 주소는 공용 HTTPS 화면으로 이동한다.
- 체험 화면에서는 실제 음성 접수를 열 수 없다는 안내를 표시한다.
- YouTube 링크 연결·변경 및 공식 Data API를 사용하는 제목 검색 경로를 추가했다. 검색 키는 서버 환경에만 보관한다.

## 남은 실제 환경 검증

- YouTube 제목 자동 검색은 공용 서버에 키를 설정하고 실제 Google API 검색을 확인했다. 독립 체험 공간에서 `!내정보` → `!신청곡 아이유 좋은 날` → **이 곡 재생**으로 검색된 영상이 로드되고 플레이어가 **재생 중**으로 전환됨을 확인했다. 브라우저 오류·경고 로그는 없었다. 실제 스피커 소리와 스푼 송출 소리는 이 검증에 포함하지 않는다.
- 실제 iPhone/Android 마이크 권한, 녹음·전송·스피커 출력은 사용자 기기에서 확인이 필요하다.
- YouTube 임베드 허용 여부와 소리 자동재생 제한은 영상과 브라우저에 따라 다르다. DJ의 첫 재생 조작이 필요할 수 있다.
- 관리 화면에서 재생한 소리를 스푼 방송에 송출하려면 DJ 방송 장치의 오디오 입력 설정을 확인해야 한다.
- 일본 서버는 지역 설정 및 모의 API 테스트를 통과했지만 실제 일본 DJ 계정으로 검증하지 않았다.
- 임시 HTTPS 주소는 PC·서버·터널 실행에 의존한다. 상시 운영과 고정 주소는 별도 배포가 필요하다.

실제 계정의 결제, 청취자 데이터 삭제 등 되돌리기 어려운 동작은 운영 데이터에서 실행하지 않았다. 테스트 전용 데이터에서 검증한 결과와 실제 외부 서비스 검증을 구분한다.

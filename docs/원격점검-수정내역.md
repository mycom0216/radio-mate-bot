# 원격 점검 및 개선 기록

기준일: 2026-11-17. 대상은 현재 작업 폴더의 Spoon Studio와 청취자 음성 입력 확장입니다.

## 수정한 오류

1. **한정 재고가 이전 값으로 돌아가는 경합**: 아이템 구매로 유한 재고가 줄어들 때 설정 revision도 증가시킵니다. 오래 열어 둔 관리 화면의 저장은 409로 거절됩니다. 실패한 구매·중복 이벤트·무제한 재고 구매는 revision을 불필요하게 올리지 않습니다. 엔진 테스트와 실제 HTTP 저장 충돌 테스트로 확인합니다.
2. **현재곡이 있으면 대시보드의 다음 곡이 안 보이는 문제**: 현재곡 표시와 다음 대기곡 표시를 함께 렌더링하도록 고쳤습니다. 테스트 신청곡 두 개로 화면에서 확인했습니다.
3. **중간 너비에서 숫자 입력칸이 옆으로 넘치는 문제**: 입력 필드의 최소 너비와 그리드 열을 수정했습니다. 실제 관찰 너비 984px에서 넘침이 사라졌고 375px 전체 12개 메뉴에서도 페이지 가로 넘침이 없었습니다. 표 자체는 내부 스크롤을 유지합니다.
4. **요청이 끝없이 기다리거나 영문 네트워크 오류만 보이는 문제**: 일반 API 15초·명령어 테스트 30초 제한과 한국어 오류 안내를 적용했습니다. 네트워크 실패나 시간 초과 후 지급·사용 요청을 자동 재시도하지 않으며 처리 기록 확인을 안내합니다.
5. **빠른 메뉴 이동의 늦은 응답**: 마지막 메뉴 이동 요청만 화면에 반영하고, 지급·저장 처리 중 이동을 막아 늦은 응답이 화면을 덮어쓰는 경우를 줄였습니다.

## 추가한 기능

- 명령어 안내에서 명령어와 기능 설명을 검색할 수 있습니다. 결과가 없는 분류는 숨기고 일치 개수를 표시합니다.
- **청취자 전용 음성 입력 확장**: `extensions/listener-voice`. 한국어 한 문장을 인식해 스푼 웹 채팅 입력창에 붙입니다. 기존 초안 보존, 요청 ID 중복 방지, 입력 길이 확인, 주소 변경 감지, 취소·마이크 오류 안내를 포함합니다. DJ 관리 메뉴에 음성 채팅을 추가하지 않았습니다.
- 청취자 안내 화면: `http://localhost:4310/listener/`. 이 페이지는 설치 전 미리보기이며 실제 방송 입력 연결에는 확장 설치가 필요합니다.
- 설치·사용 안내: `http://localhost:4310/listener/guide.html`.

확장은 **자동 입력까지만** 수행합니다. 채팅 전송은 스푼 화면에서 직접 합니다. 봇 API를 사용해 개인 청취자 계정을 흉내내지 않으며, DJ 방송 송출·방송 제어·비밀번호·쿠키 조회 기능이 없습니다. 스푼 모바일 앱을 조작하지 않습니다.

점검용 ID는 `qa-review-1117`입니다. 기존 청취자 잔액을 변경하거나 사용자 데이터를 초기화하지 않았습니다. 점검용 신청곡은 정상 완료 처리했으며 게임 스위치는 처음과 같이 OFF로 되돌렸습니다. 점검용 프로필과 감사 기록은 구분 가능한 상태로 남겼습니다.

## 실제 환경에서 남은 확인

확장을 설치한 Chrome에서 실제 마이크 한국어 인식, 로그인된 스푼 계정의 입력 반영·수동 전송을 확인해야 합니다. 자동 테스트는 인식 서비스나 실제 스푼 전송 성공을 보장하지 않습니다. 음성은 브라우저 제공자의 서버로 전송될 수 있으며 이 앱 서버에 녹음 파일을 저장하지 않습니다.

스푼 공식 OAuth/SSE 송신·토큰 갱신, 장시간 방송, 실제 모바일 기기와 음성 파일 녹음, 공개 HTTPS 배포·전체 백업 복원은 이번 로컬 원격 점검과 구분합니다. 확장 설치는 사용자 동의를 받은 뒤 진행할 단계입니다.

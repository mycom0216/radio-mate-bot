개인정보와 데이터 보관 안내

이 서비스는 방송의 신청곡·게임·음성 접수를 관리합니다. 운영자와 삭제 요청 창구는 접속한 방송의 DJ에게 문의하세요.

수집·이용

스푼이 제공한 앱 범위 청취자 ID·닉네임, 명령과 보상·출석·신청곡 기록을 기능 제공과 중복 지급 방지에 사용합니다. 청취 자동 보상이 켜져 있으면 현재 청취자 목록과 연속 확인 시각으로 청취 시간을 추정하여 내부 애청지수·복권 지급량을 저장합니다. 매시간 첫 채팅 참여 점수도 순위에 반영합니다. DJ가 별도로 연결한 이메일은 서버 비밀키로 만든 해시만 저장하고 원문은 보관하지 않으며, 계정 ID 별칭은 해당 DJ 방송에서만 사용합니다. 로그인은 기존 12시간 만료를 유지하며 세션 내용을 암호화 저장해 서버 재시작에도 유지합니다. 음성 접수는 입력한 닉네임·제목·음성 파일을 수집합니다. 음성은 해당 DJ만 조회할 수 있습니다. 접수 IP는 전송 횟수 제한을 위해 메모리에 잠시 보관합니다.

스푼 연결 토큰은 서버에서 암호화 저장합니다. 비밀번호를 수집하지 않습니다. 음성 입력 확장 프로그램은 브라우저 음성인식 서비스를 사용할 수 있으므로 해당 서비스의 개인정보 정책도 확인하세요. YouTube 플레이어와 공개 접속에 사용하는 HTTPS 제공자에게 연결 정보가 전달될 수 있습니다.

앱 채팅 · AI · 검색

앱 채팅방의 표시 이름과 메시지는 해당 방송 참여자와 DJ에게 공개됩니다. 스푼 계정 인증과 별개이며 최근 100개, 7일 동안 표시합니다. 전송 제한을 위한 IP 기반 해시는 메시지와 함께 저장하며 원문 IP는 저장하지 않습니다. DJ는 채팅 삭제·링크 갱신·입장 중지가 가능합니다. 자유로운 AI 대화는 질문과 최근 6쌍의 대화를 OpenAI에 전송하며 응답 저장 옵션은 끕니다. 서비스 제공자의 별도 데이터 보관 정책이 적용될 수 있습니다. AI 문맥은 서버 메모리에 마지막 성공 응답부터 30분간 보관하며 서버 재시작·초기화 시 사라집니다. 스푼으로 보내는 AI 답변은 전송 기록에 최대 7일간 남습니다. 날씨에는 Open-Meteo, 장소 검색에는 네이버에 검색 지역·종류가 전송됩니다. 인증키는 서버에서만 사용합니다.

공개 테스트 공간

공개 테스트가 켜진 서버에서는 방문자별로 분리된 메모리 DB를 사용합니다. 테스트 데이터는 1시간 후, 로그아웃 또는 서버 재시작 시 삭제되며 실제 방송 DB·백업·스푼 토큰과 공유하지 않습니다. 테스트 화면에는 개인정보를 입력하지 마세요. 실제 음성 접수는 공개 테스트에서 지원하지 않습니다.

후원 순간 캡처 확장

DJ가 연결한 PC 확장은 해당 DJ의 후원 이벤트(닉네임·스푼 수량·시각)를 받아 선택한 스푼 방송 탭의 보이는 영역을 PNG로 저장합니다. 서버에는 최근 2분·최대 100건의 트리거를 두며 최대 1분 간격으로 정리합니다. PNG는 PC 다운로드 폴더에만 저장되고 서버로 업로드하지 않습니다. 화면에 표시된 채팅·닉네임·방송 이미지가 포함될 수 있습니다. 서버에서 청취자 데이터를 삭제하면 트리거도 지우지만 PC에 이미 저장된 PNG는 PC 소유자가 직접 삭제해야 합니다. 충전·카드·계좌 결제 정보는 수집하지 않습니다.

보관 기간

  • 프로필·잔액·도감·신청곡: 청취자 데이터 또는 방송 계정 삭제까지
  • 활동 기록: 최대 90일, 정리 작업 주기에 따라 최대 6시간 지연
  • 중복 처리 방지: 최근 20만 이벤트 ID
  • 전송 메시지 기록: 완료·취소·실패·만료 후 생성일 기준 7일, 대기 메시지는 10분 후 만료
  • 음성 파일: {{VOICE_DAYS}}. 기간을 설정한 경우 6시간 주기로 정리
  • 자동 DB·암호화 전체 백업: 최근 7개 날짜 사본. 별도 다운로드한 백업은 내려받은 운영자가 관리

열람·삭제·연결 해제

DJ는 운영·백업 화면에서 내 방송 데이터를 내려받고 청취자 데이터 또는 방송 계정을 삭제할 수 있습니다. 청취자는 DJ에게 열람·삭제를 요청하세요. ID로 식별할 수 없는 음성은 수신함에서 별도 삭제합니다. 삭제는 현재 DB·연결 토큰을 대상으로 하며 기존 백업은 순환 기한까지 남을 수 있습니다. 백업 복원 시 이전 삭제 요청을 다시 적용해야 합니다.

스푼 연결 해제를 누르면 로컬 연결 정보가 삭제되며 스푼 토큰 폐기를 요청합니다. 원격 폐기 실패 안내가 표시되면 스푼 계정 설정에서도 앱 동의를 해제하세요. 데이터 내려받기 파일은 음성을 포함하므로 안전한 곳에 보관하세요.

PC 계정을 모바일로 연결

PC에서 연결한 DJ 계정을 휴대폰으로 이어받습니다. 휴대폰에서 스푼 앱이나 스푼 로그인 화면을 다시 열지 않습니다.

현재 연결을 확인하고 있습니다.

1. 연결된 PC에서 코드 발급

코드를 입력한 기기는 이 DJ의 관리 화면에 로그인됩니다. 본인의 휴대폰에만 입력하세요. 코드는 3분 동안 한 번 사용할 수 있습니다.

2. 휴대폰에서 코드 입력

PC의 방송 관리 화면 → 휴대폰 연결에서 발급한 M-으로 시작하는 코드를 입력하세요. 기존 봇 호출 코드와는 다릅니다.

연결 상태 확인방송 관리 화면

아직 PC에서도 연결하지 않은 DJ는 최초 DJ 연결을 먼저 진행해야 합니다. 모바일 연결 코드는 DJ 본인만 발급할 수 있으며, 방송 중에도 기존 봇 연결을 유지합니다.
